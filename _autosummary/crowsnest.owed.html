crowsnest.owed#

What the person owes their sessions: the open manual-task issues openloops lists.

Every terminal’s status line says “30+ owed”, and the page is where the person looks for what to do, so it shows the same list (crowsnest#85): each issue, whose repository, how old, and one tap to open it. It is openloops’ list (openloops.tools.owed()), read without running any issue’s verify predicate: a scheduled page must never execute commands that an issue’s body names.

The page never fetches. refresh() writes openloops’ envelope to a cache file under the data directory, at most once per every, and the page reads that file. An envelope whose listing failed (listed: false) is kept as it is, so the page can say the list is unavailable rather than show an empty one: “nothing owed” and “could not look” must not read the same.
