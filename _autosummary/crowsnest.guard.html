crowsnest.guard#

Keep a machine’s sessions inside its memory: a spawn gate, a reaper, and OOM tiers (#171).

On 2026-10-25/26 about 25 Claude Code sessions on a 7.6 GB server filled its RAM and its swap, and the kernel OOM-killed sessions six times in two hours – the lookout among them. Three mechanisms here, each answering one way that happened:

  • The gate (gate()), which crowsnest.spawn.spawn() calls before it starts anything: a spawn is refused (SpawnRefused) when the machine already runs session_cap() sessions, or when one more would leave MemAvailable below the

    configured floor. A name in [guard] protect – the lookout – is never refused, so a watchdog restarting it always gets through. Refused, not queued: the caller (a lookout) retries when it next wakes, and that is the queue.

  • The reaper (plan(), reap()), which closes a session only when every check in DFLT_CHECKS passes: not protected, idle (never busy, waiting or running a shell), idle for idle_hours, its ledger saying it is done (triage’s safe_to_close, which never guesses), and no unlanded work in any repository it touched (unlanded()). A check that raises keeps the session – the opposite of triage’s swallow-and-decline, because here the expensive error is closing live work. Dry run unless told otherwise; each close is re-verified first and is a SIGTERM, never a SIGKILL, and is logged with the claude --resume line that brings the session back.

  • OOM tiers (oom_pass()): every registered session’s process tree gets an oom_score_adj by what it is doing, so that when memory runs out anyway the kernel takes an idle worker first and the lookout last.

tick() runs the OOM pass and then the reaper in the mode [guard] reap names; a systemd timer (units()) runs it every few minutes. Nothing here prints or exits.

Where there is no /proc (macOS), the memory test and the OOM pass are no-ops and the cap applies only when max_sessions is configured.

crowsnest.guard.gate(name, *, home=None, config=None, settings=None, mem=None, is_alive=None)[source]#

Refuse a spawn of name when the machine is full; else say what was measured.

Raises SpawnRefused when the live sessions already reach session_cap(), or when MemAvailable minus one session’s session_mb would fall below min_available. The message names the measure and the idle sessions that have been resting longest, which are what a person (or crowsnest reap) would close first. A name in protect passes always: the watchdog restarting the lookout must never be the spawn that is turned away.

crowsnest.guard.oom_pass(*, home=None, config=None, settings=None, sessions=None, proc=None)[source]#

Write each registered session’s tier into its process and every descendant.

A descendant that is itself a registered session keeps its own tier. Only registered sessions are touched: an unregistered claude -p is left to whatever else manages it. The one exception is a session’s tmux server holding a negative value – inherited when the lookout’s tree started it, and passed to every pane opened after – which is reset to 0. A process that exits mid-pass is skipped. A no-op without /proc. Returns {"set": {pid: value}, "errors": [...]}.

Return type:

crowsnest.guard.unlanded(dirs, *, since, is_landed=None)[source]#

Why work in these directories is not landed; [] when all of it is.

For every git checkout the directories are in, over the worktrees they name plus any other worktree of the repository that moved after since (a subagent’s .claude/worktrees/agent-*):

  • any change, untracked files included (ignored ones not);

  • a merge, rebase, cherry-pick, revert or bisect in progress;

  • a HEAD that is not landed (a detached session worktree included);

  • any branch of the repository that is not landed, when it moved or was committed to after since – a branch older than the session is not its work;

  • a stash pushed after since.

Landed is is_landed(repo, rev), by default on_default_branch(): merged into a remote’s default branch. Pushed is not landed, and a repository with no remote has nothing landed. Raises when git cannot answer; the caller keeps the session.

Return type:

list[str]
